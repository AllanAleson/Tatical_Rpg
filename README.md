# Tactical RPG

Um Tactical RPG inspirado em jogos de estratégia em grid, desenvolvido na Unity.

## Funcionalidades atuais

-  Movimentação em grid
-  Pathfinding (BFS)
-  Sistema de turnos
-  Seleção de unidades
-  Alcance de movimento
-  Alcance de ataque
-  Obstáculos
-  Preview de caminho
-  HUD do jogador
-  Sistema de PM (Pontos de Movimento)

## Tecnologias

- Unity 6
- C#
- Universal Render Pipeline
